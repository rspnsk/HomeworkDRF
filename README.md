# Django DRF Project
## Описание проекта

Проект создан для изучения Django REST Framework. Реализованы модели пользователей, курсов и уроков.

### Модели

Пользователь (приложение users)

Авторизация по email
Телефон, город, аватарка

Курс (приложение materials)

Название, превью, описание
Один курс содержит много уроков

Урок (приложение materials)

Название, описание, превью, ссылка на видео
Связан с курсом

CRUD

Курсы

Viewset для всех операций

Уроки

Generic-классы для CRUD
Доступны: список, детали, создание, обновление, удаление

### Клонируйте репозиторий
git clone <url>

### Установите зависимости
pip install -r requirements.txt

### Примените миграции
python manage.py migrate

### Запустите сервер
python manage.py runserver
