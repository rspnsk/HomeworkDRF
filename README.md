# Django DRF Project
## Описание проекта

Проект создан для изучения Django REST Framework. Реализованы модели пользователей, курсов и уроков.

### Модели

### 1. Пользователи и Авторизация (Users & JWT)
* Создана кастомная модель пользователя **`CustomUser`**, где поле `email` используется в качестве логина 
вместо стандартного `username`.
* Интегрирована **JWT-авторизация** (`djangorestframework-simplejwt`).
* Все эндпоинты платформы по умолчанию закрыты авторизацией. 
Исключение: регистрация и получение токенов, доступные гостям.


### 2. Управление контентом (Materials)
* Реализован полный **CRUD** для Курсов и Уроков.

### 3. Права доступа (RBAC & Права владельца)
* Группа модераторов (`moderators`): создана через кастомную команду управления. 
Модераторы могут просматривать и редактировать любые курсы и уроки, но им строго запрещено создавать 
и удалять контент (возвращается `403 Forbidden`).
* Права владельца (`IsOwner`): обычные пользователи-немодераторы видят в списке, 
могут редактировать и удалять только свои собственные курсы и уроки. 
* Реализована автопривязка автора к объекту при создании через метод `perform_create`.
Название, описание, превью, ссылка на видео

### 4. Система платежей (Payments)
* Создана модель платежей, связанная с пользователями, курсами и уроками.
* Подключена библиотека `django-filter` для эндпоинта платежей, позволяющая:
  * Фильтровать платежи по курсу, уроку или способу оплаты (наличные/перевод).
  * Менять порядок сортировки по дате оплаты (`ordering=payment_date`).

### Тесты!!!
Для проведения тестов, используйте временную настройку. 
Откройте settings.py, найдите текущий блок DATABASES (где прописан PostgreSQL) и закомментируйте его.
Сразу под ним добавьте стандартную конфигурацию для SQLite:
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
